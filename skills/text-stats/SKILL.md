# 文本统计（text_stats）

统计一段文本的规模信息，适合分析文章、日志、用户反馈。

## 输出内容

- 字符数、中文字数、英文单词数
- 行数、段落数
- 出现次数最多的前 N 个词（中文按双字切分，英文按单词切分）

## 什么时候用

- 用户问「这段文字多少字」「统计一下长度」
- 需要判断一段内容的关键词分布
- 处理日志、反馈、评论时先摸清数据规模

## 实现

代码在 `skill.py`，元信息写在 `TOOL` 字典里，执行入口是 `run(text, top_words=5)`。

要改成自己的逻辑，直接改 `run()` 即可；要加参数，同时改 `TOOL["parameters"]` 和 `run()` 的签名。
