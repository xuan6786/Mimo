## 给助手加上工具扩展层（Skill / MCP / 内置工具）

### 背景
用户在 `Y:\A_MiMo` 已有命令行 + 网页版两个入口的 MiMo 助手。本次要求「预留 MCP 和 skill 接口」，
实际交付了一条可用的统一工具总线，而不是空接口。

### 新增文件
- `mimo_tools/base.py`：`Tool` / `ToolResult` / `ToolRegistry`。工具名自动清洗为 OpenAI 规范；
  执行时只传函数签名声明过的参数（模型多给参数不会报错）；异常统一收敛成 ok=False 的结果，
  不中断对话；重名自动加命名空间前缀。
- `mimo_tools/builtin.py`：5 个内置工具（时间 / 列目录 / 读文件 / 写文件 / HTTP GET）。
  文件操作限制在 `tools.sandbox_root` 内，越界拒绝；写文件默认关闭。
- `mimo_tools/skills.py`：本地技能加载器。代码技能 = `skill.py` 里的 `TOOL` 字典 + 入口函数；
  提示词技能 = 只有 `SKILL.md`，正文拼进系统提示词。`TOOL` 支持 dict 或 list（一技能多工具）。
  零依赖，不解析 YAML，frontmatter 只支持扁平 key: value。
- `mimo_tools/mcp.py`：MCP 客户端，JSON-RPC 2.0，支持 stdio（子进程 + 读线程 + Condition 等待）
  与 Streamable HTTP（POST，响应可能是 JSON 或 SSE，处理 Mcp-Session-Id）。
  只实现 initialize / notifications/initialized / tools/list / tools/call。
- `mimo_tools/agent.py`：`AgentRunner` 多轮循环。前 max_iterations 轮带 tools，
  最后一轮摘掉 tools 逼模型出最终答案；reasoning_content 按官方建议保留在历史里；
  usage 跨轮累加。
- `mimo_tools/__init__.py`：`build_tools(config, base_dir)` 单一入口，装配三类来源；
  未开启时也返回 catalog（探测到哪些技能 / 启用了哪些 MCP），便于界面提示。
- `skills/`：3 个示例技能（text-stats 代码技能、json-tool 一技能两工具、answer-style 提示词技能）+ README
- `mcp.json`：MCP Server 配置示例（3 个默认关闭的条目）

### 改动的既有文件
- `mimo_client.py`：新增 `tool_calls` 解析——流式增量按 index 累积（`_accumulate_tool_call`
  / `_finalize_tool_calls`），非流式直接读 message.tool_calls；新增 `tool_call_start` 事件；
  补 402 余额不足的友好提示。
- `assistant.py`：新增 `--tools` / `--no-tools`、`/tools [on|off]`、`/tool 名字 {json}`；
  工具事件的可视化（⚙ 调用 / ✓ 返回 / ── 第 N 轮 ──）；启动横幅显示工具统计。
- `server.py`：新增 `/api/tools`、`/api/tools/reload`、`/api/tool/call`；
  `/api/chat` 走 AgentRunner；工具上下文全局缓存 + 按配置签名自动重建（MCP 子进程不能每请求重建）。
- `web/`：助手消息改为 parts 结构（text / tool 交替），新增可展开的工具调用卡片；
  输入框加「工具」开关；设置面板加工具清单（可点行试跑）+ 重载按钮。
- `README.md`：新增第四节完整文档（架构图、三种来源、安全边界、配置、调试）。

### 验证方式（无真实额度、无浏览器）
- mock MCP Server（stdio）+ mock 聊天服务（第一轮发 tool_calls、第二轮出答案）：
  验证 MCP 桥接、AgentRunner 多轮循环、事件序列、usage 跨轮累加，全部通过
- curl 验证 `/api/tools`、`/api/chat` 的 SSE 工具事件、`/api/tool/call`、配置读写后自动重建
- 沙箱越界、写文件未授权、非法 JSON 参数等负向用例都返回了可读的中文错误
- 真实 API 验证**失败**：`HTTP 402 Insufficient account balance`——用户账号余额不足。
  已把 402 加进友好提示表。
